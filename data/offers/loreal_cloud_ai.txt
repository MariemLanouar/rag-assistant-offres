A Day in the Life

You will contribute to building and scaling high-performance cloud and AI solutions within our global tech community of 2,000 tech experts across 40+ specialisms, collaborating closely with experienced software and cloud engineers.
• Participate in the development and deployment of Python (or TypeScript/C#) applications and microservices.
• Support the design of scalable cloud architectures across Google Cloud Platform (GCP), Microsoft Azure, or AWS.
• Assist in integrating modern AI frameworks, including Retrieval-Augmented Generation (RAG), vector embeddings, and multi-tenant structures into real-world use cases.
• Contribute to continuous integration and continuous deployment (CI/CD) pipelines and maintain clean Git versioning across code repositories.
• Help evaluate emerging AI development tools to optimize daily engineering workflows and strengthen system security.

We Are Looking For

You bring a builder mindset, a curiosity for cutting-edge cloud infrastructure, and practical coding experience. You bring:
• Software Development: Solid proficiency in Python, JavaScript/TypeScript, or C#, demonstrated through personal code repositories, open-source contributions, or technical hackathons.
• Cloud Computing: Practical understanding of public cloud fundamentals (GCP, Azure, or AWS) and API-driven architectures.
• Artificial Intelligence: Hands-on familiarity with practical AI concepts, including RAG patterns, embeddings, or agentic developer tools.
• DevOps & Tooling: Experience with Git version control and exposure to automated deployment workflows or modern coding environments.
• Communication & Teamwork: Professional working proficiency in English; operational French is required for specific project assignments.
