Your Role And Responsibilities

What You’ll Do

Building a centralized and reliable data pipeline

Collecting, cleaning, and inventorying nat cat claims data stored across various sources and formats (Excel, CSV, JSON, etc.)
Designing and implementing an ETL (Extract, Transform, Load) pipeline in Databricks to automate data ingestion, cleaning, and standardization
Applying data quality checks and validation rules to ensure accuracy and consistency of the data

Developing a user-friendly data loading/extraction interface

Creating an intuitive interface within Databricks (e.g., using Databricks Widgets or a notebook-based UI) allowing non-technical users to load/submit data with ease.
Implementing clear error messages and guided workflows to support data contributors across teams.

 Enabling data visualization and self-service analytics

Building an interactive dashboard connected to the cleaned Databricks data layer, providing meaningful insights on the claims data
Integrating a data download feature, allowing authorized users to export clean, structured datasets directly from the platform

 Documenting and maintaining the solution

Producing clear technical documentation covering the pipeline architecture, data dictionaries, and user guides
Following data engineering best practices (version control, modular code, reproducibility)
