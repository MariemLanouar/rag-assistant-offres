Description Du Poste

Vous intégrez l'agence Digital Platform Services Ouest qui compte près de 160 collaborateurs.

Dans le cadre des travaux d’innovation autour de l’intégration de l’IA générative au sein des systèmes d'information, Sopra Steria souhaite concevoir une suite d’agents IA spécialisés, capables d’assister les équipes opérationnelles dans des contextes variés : planification, MEP, support technique, capitalisation de connaissance, etc.

Ces agents devront être conçus, entraînés, testés et déployables dans différents environnements SI, tout en préservant leur capacité à réutiliser et transférer leur savoir vers d’autres contextes (IA portable, réentraînement léger, adaptation par prompting évolutif).

Votre rôle et vos missions:

Vous étudiez les besoins fonctionnels et opérationnels.
Vous définissez l’architecture fonctionnelle des agents IA.
Vous identifiez les données d’apprentissage nécessaires.
Vous concevez les comportements via des prompts structurés, chaînes de pensée, modèles de rôle.
Vous expérimentez plusieurs LLM (open-source, cloud, souverains).
Vous mettez en place un mécanisme d’entraînement supervisé léger (fine-tuning, RAG, mémoire vectorielle).
Vous étudiez comment déplacer un agent d’un contexte A à un contexte B.
Vous testez le concept sur un exemple.
Vous intégrez les agents dans une architecture SI (containerisation, APIs, serveurs légers).
Vous mettez en place une interface simple (CLI, web minimal, Teams bot).
Vous rédigez un rapport technique complet.
Vous présentez la démarche, les résultats et l’état de l’art.

Environnement technique/fonctionnel: 

IA générative / LLM / RAG
Prompt engineering
Déploiement logiciel (Docker, API REST)
Architecture logicielle
Compréhension des processus IT (ITSM, MEP, CAB, RoadMap)
Analyse de données, structuration documentaire
